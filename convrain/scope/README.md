# scope — ฝนตอนนี้ คำเตือน และเวลาฝน (ขั้น 5 ของ pipeline)

โมดูลนี้ตอบคำถามสามข้อของคนที่อยู่ ณ จุดใดจุดหนึ่งบนพื้น จากภาพ Himawari อย่างเดียว:

1. **ตอนนี้ฝนตกอยู่ตรงไหน** — แผนที่ฝนตอนนี้ (โหมดกลางวัน / กลางคืน) + บริเวณฝนเป็น polygon บนพื้น
2. **ฝนจะมาถึงฉันไหม เร่งด่วนแค่ไหน** — คำเตือนฝนเริ่ม 3 ระดับ (ภายใน 3 ชม. / 60 นาที / 30 นาที)
3. **ฝนจะเริ่ม / หยุดกี่โมง มั่นใจแค่ไหน** — "ฝนจะเริ่มราว 15:30 น. ความมั่นใจ 45%", "ฝนจะหยุดราว 16:20 น. ความมั่นใจ 70%"

และสำหรับเมฆฝนฟ้าคะนองแต่ละก้อนที่ตัวติดตาม (ขั้น 3) เห็น: เวลาฝนเริ่ม / หนักสุด / หยุด พร้อมช่วง 50 % / 80 %

ทุกค่าที่ใช้รู้ได้ ณ เวลาภาพนั้น (ภาพปัจจุบันและภาพก่อนหน้าไม่เกิน 2 ชม.) จึงรันแบบ real-time ได้ ข้อมูลฝนภาคพื้น (เรดาร์ / มาตรวัดฝน)
ใช้เฉพาะตอนปรับเทียบค่าคงที่และตรวจผลเท่านั้น ไม่เป็นข้อมูลเข้าตอนรันจริง

## 2. แนวคิดและที่มาของโมเดล

**ดาวเทียมเห็นยอดเมฆ ไม่เห็นเม็ดฝน.** ภาพอินฟราเรดบอกอุณหภูมิของยอดเมฆ (ยิ่งเย็นยิ่งสูง) แต่ฝนตกจากส่วนเล็ก ๆ ใต้เมฆ —
บริเวณเมฆเย็นใหญ่กว่าบริเวณที่ฝนตกจริงหลายเท่า เพราะทั่งเมฆ (anvil) แผ่ออกไปไกลจากแกนที่มีกระแสอากาศขึ้น งานทั้งหมดจึงเป็นการหา
**ตัวบ่งชี้ทางกายภาพที่ดาวเทียมมองเห็น ซึ่งบอกว่าฝนอยู่ตรงไหนใต้เมฆ และกำลังจะเปลี่ยนเมื่อไร** แล้ววัดค่าคงที่ไม่กี่ตัวจากข้อมูล

แนวคิดหลักที่ประกอบเป็นโมเดล:

1. **ความหนาของเมฆบอกว่ามีฝนไหม ไม่ใช่แค่ความเย็น.** ผลต่างช่องหน้าต่าง B13 − B15 (split window) เล็ก = เมฆหนาทึบ (แกนที่มีฝน);
   ใหญ่ = cirrus / ทั่งบาง (มักไม่มีฝน) — ทั่งบางอาจเย็นพอ ๆ กับแกน แต่บางกว่ามาก ดัชนีสามช่อง (B11 − B14) − (B14 − B15) และ B16 − B13
   ช่วยแยกยอดน้ำแข็งบางออกจากเมฆหนาอีกชั้น
2. **กลางวันเห็นมากกว่ากลางคืน.** เมื่อมีแสงอาทิตย์ ค่าสะท้อน 0.86 µm บอกความหนาเชิงแสงของเมฆโดยตรง และ 1.6 / 3.9 µm
   บอกขนาดอนุภาคที่ยอดเมฆ (อนุภาคใหญ่ = กลไกทำฝนทำงานแล้ว) — แผนที่ฝนโหมดกลางวันจึงตัดพื้นที่ฝนหลอกใต้ทั่งออกได้มาก
   กลางคืนใช้เฉพาะอินฟราเรด ซึ่งยังใช้ได้ตลอด 24 ชม.
3. **เมฆมีวงจรชีวิต — นาฬิกาเริ่มเมื่อยอดเมฆทะลุระดับพาความร้อนลึก.** เวลาตั้งแต่จังหวะนั้นบอกได้ดีว่าเมฆอยู่ช่วงไหนของชีวิต
   และอัตราการเกิดเหตุการณ์ (ฝนเริ่ม / หนักสุด / หยุด) เพิ่มขึ้นตามอายุเมฆ ("เมฆแก่ลง")
4. **สิ่งที่อยู่เหนือจุดสำคัญกว่าภาพรวมของก้อนเมฆ.** ใต้เมฆก้อนเดียวกัน แต่ละจุดเริ่ม / หยุดฝนไม่พร้อมกัน (ต่างกันเป็นสิบนาที)
   ข้อมูลที่ช่วยเพิ่มจากนาฬิกาเมฆคือ **คอลัมน์อากาศเหนือจุดนั้นเอง**: หนาขึ้นและเย็นลง = ฝนกำลังมา; อุ่นขึ้นและบางลง = ฝนกำลังหยุด
5. **ฝนส่วนใหญ่ที่จุดหนึ่ง "เคลื่อนมาถึง".** เมฆฝนฟ้าคะนองมักมีฝนแล้วตั้งแต่ตัวติดตามเห็นครั้งแรก เวลาฝนที่จุดจึงเป็นเรื่องของ
   "ฝนที่ตกอยู่ต้นลมจะมาถึงเมื่อไร" — โมเดลใช้แผนที่ฝนตอนนี้ย้อนตามการเคลื่อนที่ของยอดเมฆ เพื่อหาว่าฝนต้นลมจะมาถึงในกี่นาที
6. **ฝนที่เกิดใหม่เริ่มจากสภาพแวดล้อม.** ในวงกว้าง (~25–50 km) สัดส่วนเมฆเย็นที่ขยายตัว ยอดเมฆที่เย็นลงเร็ว (≥ 4 K ใน 10 นาที)
   และการที่อุณหภูมิเหนือจุดเพิ่งลดลงจากค่าสูงสุดในชั่วโมงที่ผ่านมา บอกว่ากำลังมีเมฆก่อตัว — ใช้กับคำเตือนระยะ 1–3 ชม.
7. **แต่ละระยะใช้ฟิสิกส์คนละแบบ.** 1–3 ชม. ข้างหน้าเป็นเรื่องสภาพแวดล้อมและการก่อตัว, 30–60 นาทีเป็นเรื่องเมฆลึก / หนาที่เข้ามาใกล้,
   0–30 นาทีเป็นเรื่องคอลัมน์เหนือจุด — ตัวแปรของแต่ละระยะจึงต่างกัน ฝนหนักสุดมาพร้อมยอดเมฆลึกที่สุดใกล้จุด, ฝนหยุดมาพร้อมคอลัมน์อุ่น / บางลง
8. **ภูมิภาคต่างกันที่อุณหภูมิ ไม่ใช่ฟิสิกส์.** โทรโพพอสเขตร้อนสูงกว่าเขตอบอุ่น ยอดเมฆพาความร้อนลึกของไทยจึงเย็นกว่าญี่ปุ่นราว 10 K
   เกณฑ์ที่ผูกกับความสูงยอดเมฆเลื่อนตามนั้น ส่วนเกณฑ์ที่ผูกกับการเกิดน้ำแข็ง (273 / 253 K) เท่าเดิม
9. **ความมั่นใจต้องซื่อตรง.** "มั่นใจ 70 %" ต้องถูกจริงราว 7 ใน 10 ครั้ง ความมั่นใจทุกตัวจึงปรับให้ตรงกับความถี่จริงด้วยข้อมูลวันที่
   โมเดลไม่ได้ใช้ฟิต — ถ้าภาพไม่มีข้อมูลพอ โปรแกรมจะบอกความมั่นใจต่ำ แทนที่จะบอกเวลาที่ดูแม่นแต่ผิด

ทุกส่วนเป็นสมการที่เขียนได้ (logistic / hazard / Weibull) กับค่าคงที่ไม่กี่สิบตัว รันบนคอมพิวเตอร์ทั่วไปได้ภายในไม่กี่วินาทีต่อภาพ

## 3. แผนที่ฝนตอนนี้ (`rainmap.py`)

ทุกพิกเซลได้ P(ฝนกำลังตกถึงพื้น) จาก logistic หนึ่งชุดต่อโหมด:

| โหมด | ใช้เมื่อ | ตัวแปรต่อพิกเซล |
|---|---|---|
| กลางคืน | ตลอด 24 ชม. | B13; B13 − B15; B08 − B13 (ไอน้ำ); ค่าต่ำสุด / เฉลี่ย / SD ของ B13 ใน 5 × 5; B13 − B15 ต่ำสุดใน 5 × 5; สัดส่วน B13 < 235 K ใน 11 × 11; ความชันของ B13; ระยะถึงยอดเมฆเย็นเฉพาะที่ที่ใกล้ที่สุดและอุณหภูมิของมัน; B08 − B13 สูงสุดใน 11 × 11; การเย็นลงใน 10 / 20 นาที; ดัชนีสามช่อง, B11 − B13, B16 − B13, B10 − B13 |
| กลางวัน | cos(มุมเซนิธดวงอาทิตย์) ≥ 0.2 และมี B04 / B05 / B07 | ทุกตัวของกลางคืน + ค่าสะท้อน 0.86 µm / cos θ0, อัตราส่วน 1.6 / 0.86 µm, ค่าสะท้อน 3.9 µm (หักส่วนความร้อนด้วย B13), ค่าสูงสุด / ต่ำสุดของสองตัวหลังใน 5 × 5 |

- B13 เข้าแบบเป็นช่วง 5 K ด้วย (ความสัมพันธ์กับฝนไม่เป็นเส้นตรง) ค่าหายเติมด้วยค่ากลาง + ธงค่าหาย
- "เป็นฝน" = ความน่าจะเป็น ≥ เกณฑ์ของโหมดนั้น (เกณฑ์ที่ทำให้ CSI สูงสุดตอนปรับเทียบ)
- ภูมิภาคเขตร้อน: เลื่อนอุณหภูมิช่อง IR ทุกช่อง +10 K ก่อนเข้าแผนที่ (`band_offset_k`) เพราะค่าคงที่ปรับเทียบที่อุณหภูมิของเขตอบอุ่น
- **การเคลื่อนที่ของยอดเมฆ:** DIS optical flow ของคู่ภาพ B13 ห่าง 10 นาที (เกลี่ยเกาส์ σ 3 px)

**ผลิตภัณฑ์ (ชั้น 1):** ทุกภาพเขียนกริด `rain_prob_pct` (0–100) / `raining` / `day_mode` และ **บริเวณฝน** = กลุ่มพิกเซลที่เป็นฝนติดกัน (≥ 2 พิกเซล)
แปลงเป็น polygon ที่ตำแหน่งบนพื้น (แก้ parallax ด้วยยอดเมฆเย็นคงที่ของภูมิภาค) พร้อมพื้นที่ (km²), ความน่าจะเป็นสูงสุด / เฉลี่ย, จุดศูนย์กลาง และโหมด
(`RainMap.product()`, `RainMap.rain_areas()`) — ใช้เป็น "ที่ไหน" ให้ระบบติดตาม / แผนที่เว็บได้ทันที

**ค่าที่จุด:** `rain_now` = ค่าที่พิกเซลเหนือจุด, `rain_near` = สูงสุดในกรอบ ~10 km, `arrival_min` = ย้อนตามการเคลื่อนที่ไป 0, 10, 20, 30, 45, 60 นาที
แล้วหาระยะแรกที่จุดต้นลมเป็นฝน (= ฝนต้นลมจะมาถึงในกี่นาที; ไม่มี = 120), `departure_min` = ระยะแรกที่ต้นลม "ไม่เป็นฝน"

## 4. คำเตือน 3 ระดับ + เวลาฝนเริ่ม / หยุดพร้อมความมั่นใจ (`outlook.py`)

### 4.1 เส้นโค้งโอกาสฝนเริ่ม

สำหรับจุดที่ยังไม่มีฝน ที่ระยะ b ∈ {10, 20, 30, 45, 60, 90, 120, 180} นาที:

```
P_b = logistic( w0 + Σ w_j · z_j )          z = ตัวแปรของระยะนั้น ปรับมาตรฐานด้วยค่าเฉลี่ย / SD ตอนปรับเทียบ
F(b) = max(P_10, …, P_b)                     เส้นโค้งสะสม (บังคับไม่ลดลง), F(0) = 0, ระหว่างระยะเป็นเส้นตรง
```

| ระยะ | ตัวแปร (รอบจุด, เลื่อน parallax ของยอดเมฆเย็นคงที่ของภูมิภาค) | ฟิสิกส์ |
|---|---|---|
| ≤ 30 นาที | B13 และ B13 − B15 เหนือจุด และการเปลี่ยนใน 10 นาที; B13 ต่ำสุด, B13 − B15 ต่ำสุด, สัดส่วนเมฆเย็นในรัศมี ~10 km; แผนที่ฝน (เหนือจุด, ~10 km, ~25 km); ดัชนีสามช่องและ B16 − B13 เหนือจุด | คอลัมน์เหนือจุดหนาและเย็นลง ฝนอยู่ใกล้ |
| 45–60 นาที | สัดส่วนเมฆเย็น, B13 ต่ำสุด, B13 − B15 ต่ำสุด, สัดส่วนยอดที่เย็นลงเร็ว และการเปลี่ยนของสัดส่วนเมฆเย็นในรัศมี ~25 km; B13 เหนือจุด; แผนที่ฝน; ดัชนีสามช่อง, B16 − B13 | เมฆลึก / หนาเข้ามาใกล้ |
| 90–180 นาที | สัดส่วนเมฆเย็นและการขยายใน 30 นาที, สัดส่วนยอดที่เย็นลงเร็ว, B13 ต่ำสุด ในรัศมี ~50 km; การลดลงของอุณหภูมิรอบจุดจากค่าสูงสุดใน 2 ชม.; ช่วงเวลาของวัน; แผนที่ฝน — **ค่าคงที่แยกกลางวัน / กลางคืน** | สภาพแวดล้อมและการก่อตัว (วัฏจักรรายวัน) |

### 4.2 คำเตือน 3 ระดับ

| ระดับ | เงื่อนไข | ความหมาย |
|---|---|---|
| `imminent` (ใกล้ตก) | F(30) ≥ เกณฑ์ | ฝนอาจเริ่มภายใน 30 นาที |
| `warning` (เตือน) | F(60) ≥ เกณฑ์ | ฝนอาจเริ่มภายใน 60 นาที |
| `watch` (เฝ้าระวัง) | F(180) ≥ เกณฑ์ | ฝนอาจเริ่มภายใน 3 ชม. |

เกณฑ์แต่ละระดับคือค่าที่ให้ CSI สูงสุดบนข้อมูลที่โมเดลไม่ได้ใช้ฟิต; ถ้าเข้าหลายระดับ แสดงระดับที่เร่งด่วนที่สุด;
จุดที่แผนที่บอกว่ากำลังมีฝน แสดง `raining`

### 4.3 "ฝนจะเริ่มราว HH:MM ความมั่นใจ Y%"

- **เวลาที่บอก** = กึ่งกลางของหน้าต่าง 30 นาที (±15) ที่มีความน่าจะเป็น F(L + 15) − F(L − 15) มากที่สุด
  (ไม่ใช่มัธยฐาน: การกระจายของเวลารอฝนเบ้ไปทางสั้น หน้าต่างที่มีโอกาสมากสุดจึงตอบโจทย์ "ถูกภายใน ±15 นาที" ได้ดีกว่า)
- **ความมั่นใจ** = ความน่าจะเป็นในหน้าต่างนั้น ปรับให้ตรงความถี่จริง (isotonic regression บนผลของวันที่โมเดลไม่ได้ใช้ฟิต)
  → "ความมั่นใจ 45 %" = ในสถานการณ์แบบนี้ ฝนเริ่มภายใน ±15 นาทีของเวลาที่บอกราว 45 ใน 100 ครั้ง (รวมกรณีที่ฝนไม่มาเลย)

### 4.4 "ฝนจะหยุดราว HH:MM ความมั่นใจ Y%"

สำหรับจุดที่แผนที่ฝนตอนนี้บอกว่ากำลังมีฝน: เส้นโค้งโอกาสฝนหยุดที่ระยะ 10 … 120 นาที (ตัวแปรชุดเดียวกับระยะ ≤ 30 นาทีของฝนเริ่ม:
คอลัมน์อุ่นขึ้น / บางลง, ฝนรอบจุดลดลง) แล้วบอกเวลาและความมั่นใจด้วยวิธีเดียวกัน

**นิยามที่ใช้ปรับเทียบ** (ฝนที่จุดเป็นช่วง 10 นาที): ฝนเริ่ม = ช่วงแรกที่เปียกหลังแห้งต่อเนื่อง 60 นาที; ฝนหยุด = ช่วงแรกของ
ช่วงแห้ง 2 ช่วงติดกัน (แห้ง ≥ 20 นาที กันการหยุดหลอก)

## 5. เวลาฝนของเมฆที่ติดตาม

### 5.1 นาฬิกาเมฆ t0 และสายตระกูล

- **t0 ของ track = scan แรกที่แกนลึก (B13 < 235 K ไทย / 245 K ญี่ปุ่น) มีอย่างน้อย 4 พิกเซล** คือจังหวะที่ยอดเมฆทะลุระดับพาความร้อนลึก
  — เป็นนาฬิกาทางกายภาพของเมฆ ไม่ขึ้นกับว่าตัวตรวจจับเห็นวัตถุครั้งแรกเมื่อไร
- **การแตกตัว:** track ลูก (`parent_id`) รับ t0 และประวัติของพ่อแม่ — เมฆก้อนเดียวกันที่ตัวติดตามแยกเป็นหลาย track ยังมีนาฬิกาเดียวกัน
- **t0_censored:** track ที่เห็นครั้งแรกก็มีแกนแล้วและไม่มีพ่อแม่ (เริ่มข้อมูล / หลังข้อมูลขาด) — ยังทายได้ แต่ t0 อาจช้ากว่าจริง
- ข้อมูลขาดเกิน `ingest.max_gap_min` → นาฬิกาเริ่มใหม่พร้อมตัวติดตาม

### 5.2 ตัวแปร

| ตัวแปร | ความหมาย | ฟิสิกส์ |
|---|---|---|
| `t`, `b` | เวลาออกคำทำนาย, t0 ของสายตระกูล (นาที) | อายุเมฆ `t − t0` |
| `d2` | ระยะ Mahalanobis² จากจุดถึงวงรีแกน (ตัดที่ 16) | จุดอยู่ใต้แกนหรือห่างออกไปกี่เท่าของขนาดแกน |
| `st_btd` (= `btd`) | B13 − B15 ของพิกเซลเหนือจุด | เล็ก = เมฆหนาทึบ (ฝน) |
| `d_b13_10`, `d_b13_20` | B13 ตอนนี้ − 10 / 20 นาทีก่อน ที่จุดเดิมบนพื้น | ลบ = คอลัมน์เย็นลง: ยอดสูงขึ้นหรือแกนเคลื่อนเข้ามา |
| `d_btd_10` | B13 − B15 ตอนนี้ − 10 นาทีก่อน | ลบ = เมฆเหนือจุดหนาขึ้น |
| `warm_20` | max(`d_b13_20`, 0) | คอลัมน์อุ่นขึ้น: แกนผ่านไปแล้วหรือกำลังสลาย |
| `depth_6` | B13 ต่ำสุดในรัศมี ~6 km − เกณฑ์แกนของภูมิภาค | ลบมาก = ยอดเมฆลึกมากใกล้จุด (กระแสอากาศขึ้นแรง) |
| `rain_now`, `rain_near` | แผนที่ฝนตอนนี้เหนือจุด / สูงสุดใน ~10 km | ฝนอยู่ใกล้แค่ไหน |
| `rain_arrival` | ln(`arrival_min` + 10) | ฝนต้นลมจะมาถึงในกี่นาที |
| `clock_prior` | ln(เวลาที่นาฬิกา Weibull ทายว่าเหลือ + 10 นาที) | ข้อมูลวงจรชีวิตเมฆ ส่งต่อให้ hazard รายช่วง |

### 5.3 นาฬิกา Weibull (รู้อายุเมฆ)

ให้ u = t_เหตุการณ์ − t0 + 60 นาที และ s = t − t0 + 60

```
S(u) = exp(−(u/λ)^k)                    ความน่าจะเป็นที่ยังไม่เกิดถึงเวลา u
ln λ = a + b1·z(d2) + b2·z(btd)        z = มาตรฐานด้วยค่าเฉลี่ย / SD ของข้อมูลปรับเทียบ
u_q = λ·[ (s/λ)^k − ln(1 − q) ]^(1/k)  ควอนไทล์ q เมื่อถึงเวลา t ยังไม่เกิด;  เวลา = t0 − 60 + u_q
```

k > 1 = อัตราเกิดเหตุการณ์เพิ่มตามอายุ (k ≈ 1.7 ฝนเริ่ม / หนักสุด, ≈ 2.0 ฝนหยุด); BTD เหนือจุดเล็ก (เมฆหนา) → เหตุการณ์มาเร็ว;
ตัวขยายช่วง c ปรับให้ช่วง 50 / 80 % ครอบคลุมตามชื่อ

### 5.4 hazard รายช่วง

```
h_k = logistic( a0 + a1·ln k + Σ_j β_j·z_j + Σ_j∈tv γ_j·z_j·ln k )      k = ช่วง 10 นาทีที่ 1 … 18 (3 ชม.)
F(10k นาที) = 1 − Π_{i ≤ k} (1 − h_i)                                    ควอนไทล์ = เวลาที่ F ถึง q; เกิน 3 ชม. ใช้หางของนาฬิกา Weibull
```

γ·z·ln k คือผลที่เปลี่ยนตามระยะ: สัญญาณของคอลัมน์อากาศมีผลแรงเมื่อเหตุการณ์ใกล้และจางลงเมื่อไกล

| เหตุการณ์ | z | ผลตามระยะ (tv) |
|---|---|---|
| ฝนเริ่ม | clock_prior, st_btd, d_b13_10, d_btd_10, rain_now, rain_near, rain_arrival | st_btd, d_b13_10 |
| ฝนหนักสุด | clock_prior, st_btd, d_b13_10, depth_6, rain_now, rain_near, rain_arrival | st_btd, depth_6 |
| ฝนหยุด | clock_prior, st_btd, warm_20, d_btd_10 | warm_20, d_btd_10 |

**ฝนหยุดใช้ตัวสลับ:** hazard รายช่วงเมื่อตัวมันเองทายว่าเหลือ ≤ 30 นาที ไม่งั้นนาฬิกา Weibull (ตัดสินจากคำทำนายของตัวเอง ไม่ใช่เวลาจริง)
— สัญญาณอุ่นขึ้น / บางลงชัดเมื่อใกล้หยุด ส่วนระยะไกลวงจรชีวิตเมฆบอกได้ดีกว่า
**ลำดับในผลที่ส่งออก:** จัดให้ เริ่ม ≤ หนักสุด ≤ หยุด ในทุกควอนไทล์

### 5.5 จับคู่จุดกับเมฆ

แต่ละจุดใช้สายตระกูลที่วงรีแกนใกล้ที่สุด (d² ต่ำสุด) และทายเฉพาะเมื่อ d² < 16 (ภายใน 4σ ของแกน); รายวัตถุประเมินที่จุดใต้ศูนย์กลางแกน

## 6. parallax

ยอดเมฆสูง H ปรากฏเยื้องออกจากจุดใต้ดาวเทียม (0°, 140.7°E) ไปราว H·tan(มุมเซนิธดาวเทียม) — เหนือไทย ~13–21 km สำหรับยอดเมฆ 200 K
- พิกเซลเหนือจุด (`columns.py`): แก้ทุกพิกเซลด้วยความสูงของตัวเอง H = (300 − B13) / 6.7 km แล้วเลือกพิกเซลที่ตำแหน่งจริงห่างจุด ≤ 1.5 km
  (หลายพิกเซล → เลือกที่เย็นที่สุด เพราะเมฆสูงบังเมฆต่ำ)
- หน้าต่างรอบจุด (แผนที่ฝน, คำเตือน, `depth_6`): ย้อน parallax ของยอดเมฆเย็นคงที่ของภูมิภาค (ไทย 220 K, ญี่ปุ่น 230 K)
- ศูนย์กลางแกน: เลื่อนทั้งรอยด้วยเวกเตอร์เดียวจากเปอร์เซ็นไทล์ 5 ของ B13 ในรอย

## 9. ใช้งานในโค้ด

```python
from convrain.config import load_config
from convrain.pipeline import ConvRainPipeline

cfg = load_config("config/japan.yaml", overrides={"timing": {"points_file": "points.csv"}})
pipe = ConvRainPipeline(cfg)
res = pipe.step(scan)                    # ส่ง scan ตามลำดับเวลา
res.rainmap["areas"]                     # บริเวณฝนตอนนี้ (GeoJSON Feature บนพื้น); res.rainmap["p"] = กริดความน่าจะเป็น
res.outlook                              # ทุกจุด: warning_level, onset_time, onset_confidence, stop_time, stop_confidence, ...
res.points                               # จุดใต้เมฆที่ติดตาม: onset / peak / stop q10 … q90
res.document["objects"][0]["onset"]      # รายวัตถุ: P30, P60, ETA, ช่วง 50 %
```

**คอลัมน์ของ outlook:** `scan_time, point, lat, lon, mode` (day / night), `rain_now, raining_now, p_onset_30, p_onset_60, p_onset_180,
warning_level` (none / watch / warning / imminent / raining), `onset_in_min, onset_time, onset_confidence, stop_in_min, stop_time,
stop_confidence` — เวลาเป็น UTC นับจากเวลาภาพ (ดูเรื่องความหน่วงของข้อมูลใน README หลัก)

**คอลัมน์ของ points:** `point, lat, lon, object_id, d2, age_min, t0`, `onset_q10 … onset_q90`, `peak_q10 … peak_q90`,
`stop_q10 … stop_q90` (UTC), `onset_p30, onset_p60` และตัวแปรคอลัมน์อากาศ / แผนที่ฝน; ช่วง 50 % = q25 … q75, ช่วง 80 % = q10 … q90

## 10. ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `timing.py` | `ScopeTiming.step(scan, tracks)` → `TimingResult(objects, points, outlook, rainmap)`; โหลดค่าคงที่ / จุด |
| `rainmap.py` | `RainMap`: แผนที่ฝนตอนนี้ (กลางวัน / กลางคืน), บริเวณฝนบนพื้น, การเคลื่อนที่ของยอดเมฆ, ค่าที่จุด |
| `outlook.py` | `PointFeatures` (ตัวแปรรอบจุด), `Outlook` (คำเตือน 3 ระดับ + เวลาพร้อมความมั่นใจ) |
| `outlook_fit.py` | ปรับเทียบ / ประเมินคำเตือนและเวลาพร้อมความมั่นใจ (offline) |
| `lineage.py` | `LineageBook`: สายตระกูล, t0, สถิติรอย / แกน |
| `columns.py` | `ColumnSampler`: เก็บภาพ ≤ 30 นาที แล้วตอบค่าคอลัมน์ของจุดใดก็ได้ |
| `clock.py` | `WeibullClock`, `FixedClock` (นาฬิกาตายตัวสำหรับเทียบ), `widen` |
| `hazard.py` | `LightHazard` (hazard รายช่วง), `Switch`, `EVENT_FORMS`, `from_dict` |
| `calibrate.py` | นิยามเหตุการณ์ที่จุด, จับแถวกับฝน, ฟิตค่าคงที่ของเวลาฝน, คะแนนตามระยะเวลา (offline) |
| `params.py` | โหลดค่าคงที่ของภูมิภาคจาก `constants/` |
| `geometry.py` | parallax, ระยะ, วงรีแกน, ดัชนีพิกเซลบนพื้น |
